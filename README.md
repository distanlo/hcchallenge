# O's Haircut Challenge

A neon 80s-inspired pixel salon game where O races to style three customers before their patience runs out.

## GitHub Pages

1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the **main** branch and **/root** folder, then save.

After a minute or two, your game will be available at:
`https://<your-username>.github.io/<your-repo-name>/`

## Local preview

Open `index.html` in your browser, or run a simple server:

```bash
python3 -m http.server
```
